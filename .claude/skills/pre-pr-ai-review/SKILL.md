# Pre-PR AI Review

在创建 PR 前对最终改动做独立、证据优先的审查。目标是尽早修复确定性问题，并把简短、可复查的结论交给 PR；不要代替测试、Eval-Gate 或人工决策。

## 1. 收集最小必要上下文

1. 确认当前分支、工作区状态和目标基线。默认基线为 `origin/main`；若不可用，说明原因后使用 `main`。
2. 审查 merge-base 到当前工作区的 diff、统计和未跟踪文件；不要只审查最后一个 commit。
3. 读取与改动直接相关的 spec / ADR / 测试，以及仓库 `AGENTS.md`。仅在需要确认调用链、schema 或契约时扩展阅读相邻文件。
4. 不读取或传递 `.env*`、凭据、生产数据库、构建产物、依赖目录或无关全文日志给 reviewer。

优先使用独立的 AI 会话或不同工具审查。若同一工具完成编码和审查，必须新开上下文，只提供本节收集的材料和验收目标，避免让模型为自己的实现背书。

## 2. 按风险路由

| 命中范围 | 审查重点 | 额外门禁 |
|---|---|---|
| `src/lib/agents/(analyzer|validator|followup|report-gen)/`、`src/lib/runtime/llm.ts`、`src/lib/sources/`、`evals/dataset/` | AI 输出、来源、引用校验、评测覆盖 | 必须调用 `eval-gate`，由它选择正确 eval 和证据 |
| `src/lib/db/`、schema、迁移 | 兼容性、数据保全、回滚、真实迁移路径 | 审查迁移与回滚，运行受影响测试 |
| `src/app/api/`、认证、部署、`.github/`、`.githooks/` | 输入边界、权限、secret、CI/发布影响 | 审查最小权限与失败路径 |
| UI、工具函数、文档 | 验收标准、边界用例、链接和最小测试 | 轻量审查 |

同一改动命中多类时按最高风险执行。不要把不执行本次改动路径的 A1 结果当作质量证明；`eval-gate` 已规定 report-gen 确定性路径应使用哪些回归证据。

## 3. 执行证据优先审查

按以下优先级审查，并只报告能定位到 diff、测试或仓库规则的结论：

1. **Blocking**：密钥/个人或生产数据泄露；绕过 `src/lib/sources/`；报告引用绕过 validator 白名单；破坏性数据变更没有迁移或回滚；高风险 AI 改动没有实际 Eval 证据。
2. **Warning**：验收标准、错误路径、并发或幂等性、依赖升级、测试覆盖、部署兼容性存在可验证风险。
3. **Suggestion**：可读性、命名、重复或文档改善。不得把偏好伪装成阻塞项。

每条发现必须包含严重级别、`文件:行号`、证据、影响和可执行建议。无法证实的内容标为“待确认”，不要编造问题。审查默认只报告，不直接修改代码。

特别核验：

- 第三方抓取是否仍经 `src/lib/sources/`，依赖方向是否为 `src/app -> src/lib/agents -> src/lib/sources`；
- 发布报告的引用是否来自已验证的 validator 结果；
- 新依赖是否有必要，是否影响安全、体积或维护；
- 测试是否走生产等价路径，而非方便的替身；
- 高风险 AI 改动的 eval 是否覆盖实际改动路径、相对基线是否满足门槛、产物是否可复查。

## 4. 输出、修复与交接

使用以下格式输出。没有发现时明确写“无”，不要省略栏目：

```md
## Pre-PR AI Review

- 基线：`origin/main` @ `<sha>`
- 范围：`<文件/模块>`
- 风险级别：低 / 中 / 高
- 结论：通过 / 需修复 / 待确认

### Blocking
- 无 / `<文件:行号> — 证据、影响、建议>`

### Warning
- 无 / `<文件:行号> — 证据、影响、建议>`

### 验证与证据
- 已运行：`<命令和结果>`
- Eval：不适用 / `<命令、基线对比、产物路径或链接>`

### PR 交接
Blocking：0；Warning：`<n>`（已处理 / 待人工确认）。
```

修复 Blocking 项后只复查相关 diff；最多两轮。仍有未解决项时，不宣称通过，并将其列入 PR 的 Review 关注点。PR 中只保留上述摘要、指标表和可复查产物链接，不提交冗长 AI 对话记录。

创建或更新 PR 后，仍应由 PR 内的独立 AI review 核对最终 diff 与该摘要是否一致；它是复核与留痕，不替代本 skill 的前置审查。
