# Daily Brief：解析工具与模型提取的探索性核查

> 2026-10-01。仅作 S0/S1 试验选路依据；没有冻结留出集、人工原文语义复核或工具／模型 A/B 结果，不构成上线验收。

## 输入与核对方法

- 只读使用 S0 隔离 worktree 的 `export-6815e74/candidate-pool.jsonl`（SHA-256 `83c88f8274111c792ab4d45698dfefc8e52533103c7b600d509c08b5480ea207`）、31 份已确认材料的私有标签、对应原始归档和独立 SQLite 快照。没有重新访问历史网页，也没有复制生产数据库。
- 按 `content_item_id + input revision` 连接标签与导出输入，从归档 manifest 找到精确文件；用 Node 相同的 UTF-16 字符位置截取标注片段，再比对每段 SHA-256。来源类型从隔离快照的 `source.type` 读取，正文实际来源从归档 envelope 的 `source_body_origin` 读取。
- 此次仅核对**已采正文中的既有标注**。标注片段属于机械绑定及编辑范围确认，不是独立的原文语义审计；不能以它们评估未采网页／论文全文遗漏。

## 观察结果

| 来源形态 | 已确认材料 | 已采正文长度及归档情况 |
|---|---:|---|
| arXiv feed 摘要 | 13 | 1,058–1,903 个 UTF-16 字符；没有已采 PDF 全文 |
| RSS feed 文本 | 11 | 116–50,000 个字符；其中 2 份超过当前 analyzer 的默认 10,000 字符输入上限 |
| RSS 文章页 | 7 | 已采正文 1,051–5,204 个字符；7 份均有同版本原始 `article_html` 归档 |

31 份材料的已采正文均可按精确来源版本找回；31/31 的正文 SHA-256、归档文件完整性、内容版本和无证据缺口检查通过。101 个标注片段的字符位置和文本哈希全部匹配已采正文；其中 97 个位于前 10,000 字符内，4 个位于其后（E24 一段、E31 三段）。这是按**当前代码默认值**做的反事实检查；历史实际 `ANALYZE_BODY_CHARS` 环境值或完整模型请求输入尚未恢复，不能断言这些片段当时没有进入模型，也不能把候选缺失归因为模型漏提取。

文章页的 7 份原始 HTML 已归档，因此可以在同一历史版本上离线比较现有正文提取与 Readability，无须重抓当前网页。但现有标签只覆盖已采正文；若要判定新解析器是否找回重要信息，需对原始 HTML 中现有正文之外的内容做独立原文确认。arXiv 当前只采摘要，在取得受控全文之前，Docling/GROBID 没有可比较的论文输入。

## 对照顺序与判定

1. **P：解析。** 只对已证明正文缺损的文章页运行现有提取器与 Readability；输入同一归档 `article_html`，记录正文完整性、噪声、版本与逐字 quote 定位。先补原始 HTML 的独立重要事实标签。未证明缺损的页面不以“文本变长”为收益。
2. **I：输入选段。** 对 E24/E31 等长正文，在同一已采版本、同一字符／token 预算下比较当前前缀与预登记选段策略。用现有片段位置检查可见性，再用独立语义复核判断新增片段是否重要；不能以标签选段充当正式策略。
3. **C1：首次提取。** 固定同一输入、provider、model 和调用预算，比较现有 analyzer、直接字段化提示词，以及可适配同一模型的 LangExtract。LangExtract 自身调用模型，必须计入真实调用和 token；其位置映射不替代语义支持及 validator。
4. **C2：额外一调。** 只有 C1 或实际编排基线仍有重要维度缺口时，按生产可用信号触发每事件最多一次补提取；与其直接基线比较增量，保留未触发事件在完整分母中。

正式 C1/C2 的触发事件与目标维度只能由生产可用的输入和规则决定；人工标签只用于探索定位缺口与事后评分，不得作为触发器或提示模型的目标维度。用标签挑选事件或缺失字段的结果仅记 `oracle` 上限，正式试验须覆盖冻结候选全集，未触发事件仍保留在分母。本约束从旧规格/执行清单于 2026-10-05 对账承接，不表示已运行正式试验。

各臂分别记录重要事实与限定完整性、不可溯源／不支持引用、全刊关键事件召回、阅读试测、延迟和 token；P/I 的收益不得记作 C1/C2 收益。探索样本不能代替待封存的独立留出集，历史 321 个展示审计拒绝候选因缺少可恢复的来源关联，不能统算为提取失败。
