## 数据单元和分区

探索普查固定为 2026-10-03、04、05 三次 17:00 UTC 的软件工程主题定时运行；三次都计入，包括失败、无 batch、部分运行和重试。每次只使用**该次运行后、下一次预定 17:00 UTC 运行前**完成的首份认证备份，验证 DB 调用区间、SHA 和所选原文归档；逻辑 `asOf` 是备份区间结束时间，不以目录名或 manifest 创建时间替代。若该区间内无可证明快照，该 run 仍保留在分母，相关候选终态/历史记 `unknown`，不得借下一次运行后的备份回填。私有预登记原件及首轮运行前的边界修订、工作表均在 `.data/brief-density-s0/`，不提交来源正文或生产数据。

探索来源及同家族复述不得转称正式 S1 未见留出。正式留出另取策略/阈值冻结后的前瞻完整软件工程运行窗口，按来源家族隔离；固定所有运行、输入 `ContentItem` revision、可观察候选、事件、报告 artifact 的分母。旧日志缺候选级归属或无 batch 总数时单列 `unknown`，不推断为零，也不拿旧报告补足正式窗口。

| 单元 | 固定分母及身份 | 缺失/失败处理 |
|---|---|---|
| 运行 | 预先列出的每次定时 topic run，重试另记但不把失败原尝试抹掉 | 无 batch、失败、部分完成均留在运行分母 |
| 来源 | 该 run 的全部输入 source revision occurrence，按原文 hash、家族和 `asOf` 去重/关联 | 无可验证正文或 raw envelope 的单元标证据缺口，仍保留输入分母 |
| 候选 | 展示审计候选、保留 Insight、validator、选择终态和已刊 artifact 的可关联 occurrence | 被拒草稿缺候选级来源绑定时不计合格事实，归属为 `unknown` |
| 事件 | 人工按主体、行动、产品/版本/时间在固定全部来源中划分的事件，含模型未提取和未刊事件 | 无法判定家族、历史或主题归属时隔离为 `unknown`，不能假定新事件 |
| 重要维度 | 在源文中预标注、必要限定完整且与同事件其他维度不重复的命题；区分“必须保留”和“次要补充” | 仅同源、多引用、多句或文字更长不产生新维度 |

一个可供 B1 执行器选择的成员，须有自己的 `kept` 或 `kept_degraded` 展示审计、实际读者文本、唯一主引用的 `pass/support`、原文 quote/locator 与冻结 revision/raw archive 绑定、新鲜度和保守 14 天历史检查；历史截止于**该 run 实际传给分析和报告选择的冻结 `endIso`**，不以较晚备份 `asOf` 偷看后续刊物。现有 `runScheduledTopicPipeline` 将同一个 `endIso` 传给分析时间窗与报告历史查询；有 batch 时核对其 `time_window.end`，无 batch 时须从该次 dispatch/trace 证明。不能证明此截点或历史出版时点的成员记 `unknown`。人工确认的事件、独立重要维度和限定只供**评分器**使用，不传给 B1 执行器；执行器只消费冻结策略及当时生产可用的机器字段。使用人工归组标签的 oracle preview 单列理论上限，不能计为 B1 自动收益。

一个**评分适用事件**在同一冻结来源版本内有至少两个机器合格、经事后人工金标确认不同且重要的成员，并且决策时有界历史没有同事件/同命题已刊冲突；同 URL、同实体或相同/不同 `event_id` 都不能单独证明事件关系。已刊的 E04、CONTRA 只能用于探索，不能放进新事件适用分母。

## 计分与失败口径

先在固定**全部输入事件全集**中标注关键事件及其重要维度，再看各臂的成品；未发布事件计零。分别报告总体、真正单事实、多事实适用、聚合来源多事件、版本/历史边界和证据缺口分层。

| 指标 | 分子 / 分母 |
|---|---|
| B1 新增重要维度 | B1 正确展示且 A 未展示的预标重要维度 / A 未展示但同池合格候选可提供的预标重要维度；另报新增绝对数、被 B1 丢掉的 A 维度及全刊总覆盖，不能只报净字数 |
| 全刊关键事件召回 | 正确覆盖的预标关键事件 / 全部输入中预标关键事件 |
| 全刊重要维度覆盖 | 正确覆盖的预标重要维度 / 全部输入中预标重要维度；报告必须/次要两层 |
| 错并与漏并 | 跨事件/版本错并组 / 所有多成员组；应归组而未归组事件 / 全部适用事件 |
| 成员证据与限定 | 正确绑定原文的读者断言 / 全部读者断言；完整保留限定的成员 / 全部需要限定的成员 |
| 运行完成 | 成功产出受控报告的运行 / 固定全部定时运行；另列原失败、重试和空刊 |
| 阅读 | 固定理解题正确数、查证所需操作/时间、整刊阅读用时；与 A 配对，并记录自报负担 |

安全门先固定为：已检查样本中错并、无独立合格证据的展示事实、必要限定丢失均为 0，现有 `blocked`/无记录引用不得进入任何臂；`display` 和 `quote-only` 语义安全评测的 `unsafe_accept=0` 保持。零样本或全退回旧模式不能证明 B1 受益。B1 若缺足量适用样本，判**收益未证**；若完整输入、关键事件或重要维度非劣失败，判**不准 on**。B0 无适用样本记 N/A，不自动否决 B1。任何未知证据比例须随分母展示，不能从评分前删掉。

阅读材料在展示前冻结逐字文本、成员和 hash，A/B0/B1 盲序呈现固定问题；重发材料须保持同一版本并记录重复曝光。已有 E04 和全刊阅读反馈都是非盲探索，不能进入正式盲评得分。当前 `report-generation.md` 的 ≤12 事件、每条 ≤120 字及约 5 分钟目标是旧规格的暂定代理；试点须先做版本化修订，明确多成员事实预算和实际全刊时间，不能用字符截断限定。数值填写在正式留出封存前完成，之后不得按留出结果降低。

## 供给不足时的独立 C1 支线

若探索普查不足以支持 B1，先在隔离环境比较**首次提取**：同一冻结输入、模型/预算与现有安全检查，C1 相对实际选择的 B 基线报告新增正确重要维度、误接受/误拒、原文绑定、token/时间及运行失败。长文选段或开源工具可作为后续单独实验臂，不能混作 C1 的效果。C1 没有独立安全和增量收据时维持旧生产路径；不因 B1 供给不足就自动启用提取。
