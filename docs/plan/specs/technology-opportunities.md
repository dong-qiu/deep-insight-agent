# Spec: 技术机会与方向校准 (Technology Opportunities)

> V1.1 · 状态：🟠 实施中 · 2026-07-24

## 目标

把可溯源技术线索转化为可评审的研究 / PoC / 开发项目候选，同时保留方向外信号来校准或扩展当前主题规划。
系统只创建候选和建议验证动作，绝不自动立项、自动修改方向或把假设表述成事实。

## 输入 / 输出契约

| 项 | 说明 |
|---|---|
| 输入 | `TechLead`、其 `pass` 证据、主题下的 `TopicDirection` 档案 |
| 输出 | `TechLeadDirectionMap`（关系）和 `TechnologyOpportunity`（可评审候选） |
| 触发 | 技术线索在 validate 后写入时同步确定性投影；方向变更后可重算 |
| 事实边界 | 事实只能经 `Opportunity → TechLead → TechLeadEvidence → Citation(pass)` 读取；论点、验证动作和预期收益一律标为假设 / 建议 |

## 核心对象

`TopicDirection` 是主题下 3–6 个可演化的技术方向，记录目标能力、问题、范围、关键问题、约束和成功信号。

`TechnologyOpportunity` 是讨论立项的最小单元；它可以是方向内研究候选，也可以是相邻、远期或反证信号。

## 行为规约

1. 每个自动创建的机会必须至少关联一条已有 `TechLead`，并且该 Lead 的证据读取继续过滤 `verdict=pass`。
2. 映射分为 `core`、`adjacent`、`horizon`、`challenge` 四个通道；`horizon`/`challenge` 与方向内候选分栏展示，不与其按同一优先级混排。
3. 自动映射仅依据方向档案的显式匹配词、线索类别、重要性和可验证性确定性计算；未命中方向但满足高价值门槛的信号可进入 `horizon`，不自动创建方向。
4. 机会卡固定区分：已验证事实、待验证假设、建议验证动作、限制 / 不确定性、人工决策记录。
5. 只有 admin 可改变机会状态或创建 / 修改方向；每次状态和方向决策写入审计日志。
6. `project_candidate` 只表示“可进入立项评审”，不等价于已立项；`adopted` 也只记录人工采纳，不触发外部动作。
7. 自动投影故障必须可观测但不得阻断已校验报告发布。
8. 管理员可在方向工作台编辑完整方向档案；保存采用乐观并发版本，避免静默覆盖。
9. 匹配词变更仅标记已有候选的映射为 `stale`；管理员可先预览近期线索影响，再显式重投影。重投影不得改变既有人工机会状态。
10. 管理员界面必须分离“机会池阅读”和“方向编辑”；映射规则以核心 / 相邻 / 反证的可视化词项呈现，预览须明确新增、通道迁移和不再匹配的影响。

## 优先级

方向内机会：方向匹配 30 + 成熟证据 25 + 技术杠杆 20 + 可验证性 15 + 时机 10。

方向校准机会：战略邻接性 / 反证强度 30 + 证据成熟度 25 + 技术变化幅度 20 + 潜在影响 15 + 时机 10。

新鲜度仅代表时机，不能压过研究价值。来源等级、语义 LLM 映射和自动概念聚类留待带人工标注评测的后续阶段。

## 验收标准

- [x] AC1：每个机会可下钻至至少一条仍为 `pass` 的引用，且不会因机会层绕过现有引用白名单。
- [x] AC2：三个现有主题均有初始方向档案；方向可由 admin 查询、创建和状态管理。
- [x] AC3：同一技术线索可映射到一个或多个方向；未命中但高价值的线索只能进入 `horizon`，不会伪装成方向内机会。
- [x] AC4：机会状态变更和人工决策可审计；默认阅读页清晰区分方向内机会、校准信号与事实 / 假设。
- [x] AC5：确定性映射、优先级、证据链和生产投影均有回归测试；提供人工标注集格式和离线评分脚手架。
- [x] AC6：管理员可在技术规划页创建、完整编辑、停用方向，并获得版本冲突提示与审计记录。
- [x] AC7：词表编辑可预览近期线索的通道变化；重投影仅由管理员显式触发，保留已有人工机会状态并标记未再匹配项待复核。
- [x] AC8：方向工作台具备分层编辑、方向候选/待复核指标、规则词项可视化、差异摘要与未保存更改保护，不与机会池阅读流混排。

## 非目标

- 本版本不使用 LLM 生成技术事实、研究结论或自动立项建议。
- 本版本不自动新建 / 修改 `TopicDirection`，也不接入项目管理系统。
- 语义映射、来源权威等级和跨线索概念聚类须在收集 50–100 条人工标注样本、建立专用 eval 后另立变更。
