# 历史候选文件身份核对

目的：为 TD-09 的隔离恢复决策提供可复跑的候选核对结果，不改变生产状态。

验收标准：

- 显式传入候选目录、封存清单、清单预期 SHA-256、备份清单及独立 SQLite 快照；不读取默认 live 数据库。
- 验证清单链、快照大小/哈希和全部候选文件大小/哈希。拒绝路径穿越、重复项、符号链接、WAL 快照及伴随 WAL/SHM。
- 比较归档 RSS/Atom 条目的 URL、标题、日期与快照记录，并使用当前版本的纯归一化函数重现正文；报告分别核对标题和快照中的成功引用。未知格式不得视为通过。
- 区分内容一致性与历史字节身份。本次封存哈希、数据库正文哈希或报告标题相同，都不能认证生成时的原文件字节。正文差异、报告引用数量差异必须保留为未解决项。
- 先核对已发布报告关联的候选，再核对全部候选。终端只输出聚合；详细诊断无正文、URL，写入指定私有文件且禁止覆盖。
- 不更改 raw_ref、CitationCheck、历史报告、备份完整性标记或 TD-09 状态；不以当前来源网页替代历史档案。

独立测试涵盖错误哈希、危险路径/符号链接、未知条目、同 ID 错误元数据、正文差异和“内容一致≠历史字节认证”。
