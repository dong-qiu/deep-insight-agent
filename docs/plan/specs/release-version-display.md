# Spec: 网站发布版本标识

> 状态：已实现。仅展示随生产镜像发布的公开构建元数据；不触发部署，也不以页面标识替代运行环境核验。

## 目标

让每个页面都能低干扰地显示当前镜像的可追溯发布版本与发布时间，帮助用户和运维人员区分正在查看的发布产物。

## 设计

- 全站页脚展示 `v<package version> · <短 Git SHA>` 与 UTC 发布时间；页脚不与业务内容、告警或健康状态混淆。
- `package version`、完整 Git SHA 和发布时间在生产镜像构建时写入 `/app/build-info.json`；发布工作流在开始构建发布镜像时生成 UTC 时间。
- 本地开发或缺少构建元数据时只显示包版本和“本地开发构建”，绝不伪造发布时间。
- 显示的信息仅包含公开版本元数据，不包含镜像 digest、部署目标、凭据或运行配置。

## 验收标准

1. 已发布镜像中的任一页面均显示包版本、短 SHA 和 ISO/UTC 发布时间。
2. 每次生产镜像发布都会注入该发布对应的 SHA 与 UTC 时间；页面不从可变 Git ref 或客户端时钟推测版本。
3. 缺失或格式错误的构建元数据 fail-safe 地降级为本地开发标识，不影响页面渲染。
4. 版本解析有单元测试；完整构建继续通过。

## 已知边界

该标识证明的是镜像发布元数据，不证明该镜像已被部署或正在服务流量。生产核验仍须按运维手册比对实际运行镜像与产物。
